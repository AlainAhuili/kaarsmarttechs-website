problem: Industrial inspection jobs such as part counting or defect detection repeat the same low-level vision work on every new device.

The toolkit is extracted from the LEGO sorter's edge software. It packages frame capture, lighting normalisation, segmentation and model inference as small modules with a stable interface, so a new inspection project starts from tested code instead of a blank file.
